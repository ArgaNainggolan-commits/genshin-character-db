# Genshin Character Database

Aplikasi web interaktif yang mengonsumsi *REST API* publik untuk menyajikan data, statistik, dan informasi karakter game secara dinamis dan terstruktur.

## 🚀 Fitur Utama
* **API Data Fetching:** Melakukan permintaan HTTP secara asinkron (*asynchronous requests*) untuk mengambil data JSON dari server eksternal.
* **Dynamic UI Rendering:** Merender data karakter ke dalam antarmuka web yang responsif berdasarkan hasil *parsing* data API.

## 🛠️ Stack Teknologi
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Arsitektur & Format Data:** RESTful API, JSON.
